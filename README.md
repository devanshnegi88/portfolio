# Devansh Negi — Portfolio

Premium developer portfolio built with React 19, TypeScript, Tailwind CSS v4, and Framer Motion.

## Stack

- **React 19** + **Vite 6**
- **TypeScript** — strict mode
- **Tailwind CSS v4** (via `@tailwindcss/vite`)
- **Framer Motion** — page transitions & scroll animations
- **Recharts** — GitHub language bar chart
- **TanStack Query** — GitHub API data fetching
- **Lucide React** — icons

## Getting Started

```bash
npm install
npm run dev
```
